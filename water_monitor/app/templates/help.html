Help & runbook

What each button does, when to use it, and what the warnings mean. Written for the person who has to decide something at 11pm — shortest useful answer first.

Everyday After a pressure change Winterizing Leak tests Warnings you might see After an update

Everyday

The things worth doing regularly.

Correct a mislabelled event

Open the event on History, pick the right fixture, and press Save. This is the single most valuable thing you can do — every label improves how the next event is recognised.

History → click a row

Keep a label but stop the app learning from it

In the event's Classification section, tick “Keep my label, but don't learn from this event”. Use it when the label is right but the event is a mix of draws — a dishwasher fill with a tap running over it. Your label stays; only the pattern matching ignores it.

History → event → Classification

Mark something that wasn't real water use

Same Classification section: Not real water use removes its volume from all totals, and Ignore event hides it from learning. Both are reversible.

History → event → Classification

Take a snapshot for digging into a question

Download Study Snapshot gives a copy of the data stamped with the version it came from. Send this when something needs investigating — it is for looking at, not for restoring.

Backup → Study Snapshot

After a pressure change

A booster pump, a new regulator, or a supply change alters the shape of every draw. Two different buttons fix two different things — the names are similar, so this is the part worth reading twice.

Re-fit rules for current pressure

Re-learns the size bands that name a fixture (how big a flush is, how long a shower runs). Quick, deletes nothing. Use it when events are being given the wrong name since a pressure change.

Settings → the circuit's card

Rebuild fixture grouping for current pressure

Rebuilds the automatic grouping of similar events, ignoring pressure readings. Slower — minutes. Use it when events that are obviously the same fixture are being split into separate groups. Best after a few weeks of new events.

Settings → the circuit's card

If you are doing both: rebuild first, then re-fit

The re-fit learns from the groups, so re-fitting first means fitting to groups that are about to change. Rebuild, let it finish, then re-fit.

Clear stale group links

Reconnects events that point at fixture groups which no longer exist. Use it when the page reports orphaned events, or after an interrupted rebuild. Safe to run any time; nothing is deleted.

Water Use → Clear stale group links

Winterizing a circuit

Turn the toggle on BEFORE you drain the line

Draining empties the meter and the pressure sensor along with the pipe, so the app sees a sudden total pressure loss. Marking the circuit first tells it to expect that. Turning it on afterwards is too late — the alarm has already fired.

Settings → the circuit's card → Winterized for the season

What pauses while it is on

No water use is recorded for that circuit, no leak tests run, and it is left out of pressure learning. The other circuit is unaffected, and your history, totals and leak protection are untouched.

In the spring

Refill and re-pressurise the line first, then turn the toggle off. Normal monitoring resumes immediately, with a short quiet period so the refill itself doesn't set off an alarm.

One thing the app cannot cover

While the water is actually draining, the valve controller itself may see it as a large flow and react — that part is independent of this app and does not know about the toggle. If it trips, clear it with Reset Fault or Reset Trickle once the line is empty. Draining without routing water through the meter avoids it entirely.

Valve & Tests → Reset Fault / Reset Trickle

Leak tests

Running one

Run Now starts a test immediately; it closes the valve for a few minutes and watches whether pressure holds. Abort Test stops it and reopens the valve.

Valve & Tests

What the results mean

Passed — no leak detected: pressure held. Failed — leak detected: it didn't, and it is worth investigating. Anything starting with Aborted or Not run means the test could not measure cleanly — usually water was in use — and tells you nothing either way. It is not a failure; the next scheduled test will try again.

History → Leak tests

Tests that keep aborting

Almost always something drawing water during the test window — a softener regeneration, an ice maker, irrigation. Move the schedule to a quieter hour rather than lengthening the test.

Valve & Tests → Save Schedule

Warnings you might see

“A fixture-grouping rebuild was interrupted”

A rebuild was cut short — by a restart, usually — so the grouping is half-finished. Run Rebuild fixture grouping for current pressure again. Your labels, totals and leak protection are unaffected; only the automatic grouping is incomplete.

Settings → the circuit's card

“The add-on is still starting up”

Normal for the first 20–30 seconds after a restart, while the add-on rebuilds its fixture grouping. The page reloads itself; nothing is wrong. If it is still saying this after a few minutes, the add-on did not finish starting — check the add-on log.

For a couple of minutes after the pages come back, it is still re-checking fixture labels in the background. Everything works during that; the one exception is Download Study Snapshot (.zip), which waits until that finishes and tells you so.

A trickle alert

Sustained small flow — most often a running toilet. This comes from the valve controller, not from pattern matching, so it is worth trusting. Reset Trickle clears it after you have fixed the cause.

Valve & Tests → Reset Trickle

A safety fault

The controller shut the valve because of a burst-flow or motor problem. Faults never clear themselves — find the cause, then Reset Fault, then Open Valve.

Valve & Tests → Reset Fault

After updating the add-on

Check it actually restarted

The add-on log's first line names the version now running. If it isn't the one you expect, the old build is still up.

Give it half a minute

Startup rebuilds the fixture grouping first — about 20–30 seconds. Pages that need that data say so and reload themselves; the rest work straight away. Label re-checking then continues in the background for a couple of minutes without holding anything up.

Take a backup before anything unusual

Quick Restore is the everyday one and is small. Full Export is the complete archive. Both are on the Backup page.
